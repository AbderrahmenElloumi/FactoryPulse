## Open findings

- **P-2 · minor · 2026-11-08** — open, no ticket. The weekly DAG does not wait for the daily one (`dags/factorypulse_dag.py:79-89`). The weekly checks compare the weekly mart's `reading_count` with the current fact (`src/factorypulse/quality/expectations.py:155-160`). A daily `run_dbt_transformations` between `build_weekly_mart` and `check_weekly_quality` fails the check on correct data, and only clearing the whole weekly run fixes it. `PARALLELISM=1` does not order the DAGs (`compose.yaml:68-72` says so). A pool shared by the dbt and check tasks, or a sensor on the daily run, would close it.
- **P-3 · minor · 2026-11-08** — open, no ticket. `--indirect-selection cautious` (`scripts/dbt.sh:50`) drops the weekly mart's `relationships` test on `dim_machine` from the weekly build. The weekly quality stage checks machine ids against the fact (`src/factorypulse/quality/expectations.py:141-161`), which covers most of it.
- **P-4 · minor · 2026-11-08** — open, no ticket. The batch task passes no `data_interval` (`dags/factorypulse_dag.py:71`), so it re-ingests the whole backfill snapshot every day. An Airflow backfill of a past date does not restrict ingestion to that date.
- **P-5 · minor · 2026-11-08** — open, no ticket. On a Linux host the scheduler needs `group_add` with the Docker socket's group id; `compose.yaml:348-360` does not wire it. `docs/agents/gotchas/airflow.md` records the trap.
- **S-6 · minor, accepted risk · 2026-11-08** — open, no ticket. The scheduler mounts `/var/run/docker.sock` (`compose.yaml:355`) and the UI has no login (`compose.yaml:76-78`). The UI is published on `127.0.0.1` only, and the design prescribes the socket. Any local process that reaches port 8080 can still trigger tasks that drive the host daemon as root.
- **S-7 · minor, possible Shotgun Surgery · 2026-11-08** — open, no ticket. The cadence strings `weekly` and `post-dbt` are spelled in `dbt/models/marts/mrt_machine_weekly.sql:30`, `src/factorypulse/quality/__init__.py:30-31`, `scripts/quality.sh:24-25`, `scripts/dbt.sh:49-50,58-59` and `dags/factorypulse_dag.py:74,87-88`. Tests lock them together.
- **S-8 · minor, possible Mysterious Name · 2026-11-08** — open, no ticket. The stage `post-dbt` (`src/factorypulse/quality/__init__.py:30`) holds the daily models only, while the weekly build is also post-dbt; `daily` would say what it holds. `common` (`dags/factorypulse_dag.py:50`) holds DAG keyword arguments; `dag_kwargs` would say so.
- **T-5 · minor · 2026-11-08** — open, no ticket; needs a triage decision. The stream appends to the raw lake (`spark/streaming_ingest.py:50-53`), but the ticket's Implementation Decisions say raw ingestion merges through the shared MERGE helper. The batch DAG path merges, so checklist item 2 holds for the DAG run. Triage chooses: accept at-least-once raw ingestion in the spec, or open a ticket for a streaming MERGE.
- **V-1 · minor · 2026-11-08** — open, no ticket. `scripts/job.sh:86-87` says a late task "would start a container the scheduler no longer waits for". The scheduler does wait for it, until SIGKILL. The real risk is a job that starts after the removal pass.
- **V-2 · minor, possible Duplicated Code · 2026-11-08** — open, no ticket. `scripts/scheduler.sh:40` writes `"$JOB_OWNER_LABEL=airflow"`, and `:29` sets the same owner value. Use `$JOB_OWNER` at `:40`.
- **V-4 · minor · 2026-11-08** — open, no ticket. The `until [ -n "$stopping" ]` loop (`scripts/scheduler.sh:62-69`) runs at most once, because `wait` returns early only through `stop`. An `if` states the control flow.
- **V-5 · minor · 2026-11-08** — open, no ticket. The script runs `set -u` without `-e` (`scripts/scheduler.sh:26`). If `mktemp -d` fails (`:32`), the flag path is `/stopping`, `: >` at `:48` fails for the airflow user, and only the sweep is left. Add `|| exit 1` at `:32`.
- **V-6 · minor, possible Duplicated Code · 2026-11-08** — open, no ticket. In `tests/test_airflow_dag.py`: the removal filter repeats at `:591` and `:615`; `flag = tmp_path / "stopping"` at `:507` and `:516`; the "no run call" filter at `:512` and `:628`. - **V-7 · minor · 2026-11-08** — open, no ticket. `tests/test_scheduler_stop.py:39-43` runs `re.search(...).group(1)` at collection time, also when the opt-in tests are skipped. If the compose image line changes shape, the default host suite fails with `AttributeError`.
- **V-8 · minor · 2026-11-08** — open, no ticket. The teardown of `tests/test_scheduler_stop.py:166-172` never removes the jobs project's network `fpprobe-jobs_default`.
- **W-1 · minor, coverage · 2026-11-08** — open, no ticket. The real-daemon test `test_stopping_the_scheduler_before_its_task_starts_the_job_leaves_no_job` (`tests/test_scheduler_stop.py:203-212`) proves the flag path only. The sweep, and real Airflow tasks inheriting `FACTORYPULSE_JOB_STOP_FLAG`, are proven in the repository by fakes only. - **W-2 · minor, coverage · 2026-11-08** — open, no ticket. The branch for a signal that arrives before `scheduler=$!` (`scripts/scheduler.sh:58-59`) has no test that fails if it is deleted; `test_a_stop_that_arrives_as_the_scheduler_starts_still_stops_it` passes with the old order too. If the branch broke, the stop flag is already set, so the stop only takes the 60 s grace period.
- **W-3 · minor · 2026-11-08** — open, no ticket. Two windows remain: the crash path (`scripts/scheduler.sh:62-67`) removes once, with no flag and no sweep; a SIGKILL at 60 s during the sweep skips the final removal.
